# Detection Rules

Store custom rules or documentation for this task here.

Before committing a rule:
- Remove credentials, tokens, and private operational details.
- Add a short explanation of the event it matches and the expected alert.
- Validate the configuration against the Wazuh version used in the lab.
- Keep a backup of the original configuration.
- Do not claim a rule detects real malware unless you have safely and appropriately validated that claim.

If you include `local_rules.xml`, consider publishing only the specific custom rule and a note showing where it belongs rather than a full server configuration file.
